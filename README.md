## Hey, I'm Alex

I build AI agents and agentic workflows that do real work inside real businesses.

I led AI agent and agentic workflow rollouts at T-Mobile and Verizon, then went through Gauntlet AI, where I shipped a new project every week against problems set by hiring partners. Before all of that I spent years in SEO, AEO and web analytics, so I care a lot about what happens after launch: whether people actually use the thing and whether it moves a number.
